# Third-party licenses

Generated by `npm run licenses`. Convert has no network code; these libraries run on your computer only.

## Notes on specific components

- **ffmpeg-static**: GPL-3.0-or-later. Distributed as a separate executable that Convert starts with an argument list; it is not linked into Convert. Source for the ffmpeg build is available from the ffmpeg-static and ffmpeg projects.
- **7zip-bin**: Wrapper is MIT; 7-Zip itself is LGPL with the unRAR restriction. Started as a separate program.
- **exiftool-vendored**: ExifTool is Artistic-1.0 or GPL, started as a separate program.
- **jszip**: Dual licensed MIT or GPL-3.0-or-later. Convert uses it under MIT.
- **sharp**: Apache-2.0. libvips is LGPL-3.0 and is loaded as a shared library, not modified.
- **@vladmandic/face-api**: MIT. Ships the TinyFaceDetector weights used for offline face detection.
- **buffers**: The package.json has no license field. Pulled in by exceljs (through unzipper). Its upstream repository states MIT/X11; verify before redistributing.
- **@tesseract.js-data/eng**: MIT. English language data for offline text detection.

- ffmpeg-static@5.3.0: GPL-3.0-or-later (see notes above)
